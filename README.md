
# OtakuShelf — Anime & Manga Store

A responsive anime and manga bookstore starter made with HTML, CSS and JavaScript.

## Features
- Product catalogue
- Search and category filtering
- Price sorting
- Shopping cart and quantity controls
- Customer delivery details
- WhatsApp order requests
- Mobile-friendly design

## Setup
1. Replace sample products in products.js.
2. Add your store WhatsApp number in products.js.
3. Add your real prices, stock and contact information.
4. Test the cart and WhatsApp order request.

## Payment limitations
The payment selector only records the customer's preferred payment method. It does not process UPI, cards, wallets or online payments.

For automatic payments, use a legitimate payment gateway or e-commerce platform. Never place secret API keys in public GitHub files.

## Hosting
GitHub can store your source code, but GitHub Pages is not suitable for hosting a commercial e-commerce store. Use a hosting or store platform that explicitly allows commercial sales.

Use product photos you own or have permission to use, and sell genuine books you are authorized to sell.
